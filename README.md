# QPS 피킹 대시보드

물류센터 QPS(자동화 피킹 설비)의 **피킹 진척도, 작업대 부하, 셀 이동 추천**을 한 화면에서 보는 웹 대시보드입니다.
설치 없이 브라우저에서 바로 열 수 있습니다.

**▶ 대시보드 열기: https://jan9muk.github.io/OPPO-QPS/**

> 처음 접속하면 **시연용 목업 데이터**가 자동으로 표시됩니다. 실제 센터의 수치가 아닙니다.

---

## 주요 기능

### 1. 실시간 현황판
| 지표 | 내용 |
|---|---|
| 실시간 처리 속도 | 최근 1시간 동안 완료한 토트 수 |
| 시간당 평균 처리량 | 작업 시작 시각(13시/14시 선택)부터 누적한 시간당 처리량 |
| 신규 지시 인입 속도 | 2층 피킹 대상으로 새로 들어오는 토트 속도 |
| 2층 피킹 잔여 토트 | 아직 끝나지 않은 토트 수 |
| 분리포율 | 주문 1건이 몇 개 박스로 나뉘는지 (설비 기준 / 전체 기준) |

### 2. 현장 확인 포인트
지금 챙겨야 할 곳을 세 가지로 요약합니다.
- **피킹잔여 고빈도 SKU:** 미완료 토트가 가장 많이 걸린 상품
- **잔여 토트 상위 작업대:** 남은 작업이 많은 작업대
- **물성악화 작업대:** 2개 이상 상품이 섞인 토트가 쌓인 작업대

### 3. 호기·작업대별 부하와 진척도
- 1~3호기와 존별 지시·완료 SKU 수, 진척률, 토트당 SKU 수
- 작업대별 부하 막대: 평균선과 비교해 과부하 작업대를 색으로 표시
- 작업대별 진척도: 하위 3개 작업대 강조

### 4. 셀 이동 추천 (자동)
현재 셀 배치와 출고 지시를 분석해서 **어떤 상품을 어느 셀로 옮기면 좋을지** 추천합니다.

| 분류 | 내용 |
|---|---|
| 🚨 안전·규정 위반 | 중량물 상단 보관, 온도대·전용 구역 위반 등 즉시 조치 대상 |
| 🟢 플로우랙 진입 | 선반랙에 있는 고빈도 상품을 플로우랙으로 |
| 📦 이전 계획 | 임시 보관 구역에서 전용 구역으로 옮길 상품 |
| 🟤 전용 구역 확보 | 전용 구역을 차지한 다른 상품 퇴출 |
| 🟠 퇴출 | 물량이 줄어든 상품을 플로우랙·게이트랙에서 빼서 공셀 확보 |
| 🔵 최적화 제안 | 동선·작업대 부하·보관 높이 개선 (필수 아님) |

추천마다 **현재 셀 → 추천 셀과 사유**가 표시됩니다. 빈 셀이 없으면 같은 목록에서 **퇴출로 비게 될 셀**을 연결해 "퇴출 후 진입"으로 안내하고(먼저 뺄 상품을 사유에 표시), 그래도 없으면 "공셀 없음"으로 알려줍니다.
추천 목적지는 작업대별 부하가 한쪽으로 몰리지 않도록 추천을 하나 정할 때마다 부하를 다시 계산해 고릅니다.
온도대(냉장/냉동/5℃ 챔버), 상품군별 전용 구역(김치·계란·메추리알·축산·수산), 게이트랙·플로우랙 기준 같은 현장 운영 규칙이 반영되어 있습니다.
당장 처리하지 않을 추천은 **패스**로 목록에서 숨길 수 있고, 언제든 복구할 수 있습니다.

### 5. 존별 히트맵
존을 고르면 랙 모양 그대로 셀마다 출고 빈도를 색으로 보여줍니다.
작업대와 가까운 랙은 "W/S 최인접" 표시가 붙어서, 고빈도 상품이 먼 곳에 있는지 한눈에 볼 수 있습니다.

### 6. 카톡 공유용 캡처
버튼 한 번으로 현장 요약 화면을 이미지로 복사합니다. 카카오톡 대화창에 바로 붙여넣으면 됩니다.

## 내 데이터로 보기

WMS에서 내려받은 엑셀 파일 두 종류를 화면 상단에 **끌어다 놓거나** 파일 선택으로 올립니다.

| 파일 | 필수 컬럼 |
|---|---|
| 박스상품 상세정보 (1개) | 물류상품ID, 피킹지시수량, 배송번호, 배송박스순번, WMS배송진행상태 |
| 셀할당현황 (여러 개 가능) | 작업대, 물류상품ID, 보관위치, 랙유형, 물류분류코드, 현재고 |

- 파일 종류는 컬럼을 보고 자동으로 구분합니다.
- 셀할당현황에 **대분류·중분류·소분류**가 있으면 상품군 판정이 정확해집니다.
- 박스상품 상세정보에 **수정일시**가 있으면 처리 속도가 계산됩니다.
- 셀할당 파일을 여러 개 올리면 합쳐서 보고, 같은 셀이 서로 다르게 적혀 있으면 오류로 알려줍니다.
- 한 번 올린 데이터는 브라우저에 저장되어 다음 접속 때 바로 열립니다. 박스상품 파일만 새로 올리면 셀할당은 저장된 것을 그대로 씁니다.
- 저장된 데이터를 지우려면 화면의 **"강제 캐시 초기화"** 버튼을 누릅니다.

### 데이터는 어디로 가나요?
**올린 파일은 외부 서버로 전송되지 않습니다.** 모든 계산은 사용자 브라우저 안에서만 이루어지고, 저장도 그 브라우저에만 됩니다.

## 권장 환경
- 최신 Chrome 또는 Edge (PC 화면 권장)
- 약 7만 행 규모의 박스상품 파일 기준으로 첫 로딩은 약 5초, 이후 재접속은 약 1초 걸립니다.
